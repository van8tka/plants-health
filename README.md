# Народные рецепты

Статический сайт-каталог рецептов народной медицины: поиск, указатели по болезням,
растениям, компонентам-не-растениям и разделам, форма добавления и изменения карточек.
Работает без сервера, публикуется на GitHub Pages.

Как опубликовать: [ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md).

## Что где лежит

| Путь | Что это |
|---|---|
| `recipes/*.md` | Карточки рецептов, по одному файлу на рецепт. **Здесь вся информация.** |
| `index.html`, `assets/` | Сам сайт (страница, стили, программа) |
| `data/catalog.js` | Собранный каталог. Создаётся автоматически, руками не править |
| `scripts/build.py` | Скрипт сборки: читает `recipes/` и пишет `data/catalog.js` |
| `.github/workflows/pages.yml` | Автосборка и публикация на GitHub после каждого изменения |
| `config.js` | Имя пользователя и репозитория, если адрес сайта нестандартный |
| `шаблон-карточки.md` | Образец карточки для ручного добавления |

## Формат карточки

В начале файла между строками `---` идут поля, по ним строятся поиск и указатели:

```
---
название: "Отвар ромашки при гастрите"
что_лечит: ["Гастрит"]
раздел: "Пищеварение"
растения: ["Ромашка"]
категории_растений: ["Лекарственные травы"]
не_растения: ["Мёд"]
категории_не_растений: ["Продукты пчеловодства"]
---
```

Ниже обычный текст: заголовок, строки «**Растения:** Ромашка (Лекарственные травы)»
(из них берётся категория каждого растения), таблица «Состав», разделы
«Приготовление», «Применение», «Примечание». Проще всего создавать карточки формой
«+ Добавить» на сайте: она пишет файл в нужном формате.
