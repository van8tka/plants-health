# Как опубликовать сайт на GitHub

Пошаговая инструкция для тех, кто делает это впервые. Займёт около 20–30 минут.
В результате сайт будет открываться по адресу вида `https://ВАШЕ-ИМЯ.github.io/plants-health/`,
а новые рецепты можно будет добавлять прямо с сайта.

Всё бесплатно. Нужен только аккаунт на GitHub.

---

## Шаг 0. Проверьте сайт у себя на компьютере (по желанию)

Откройте папку `site` и дважды щёлкните файл `index.html`. Сайт откроется в браузере
прямо с диска: работают поиск, указатели, карточки. Не работает только кнопка
«Создать на GitHub»: ей нужен адрес репозитория, который появится после публикации.

---

## Шаг 1. Зарегистрируйтесь на GitHub

1. Откройте <https://github.com/signup>.
2. Введите почту, придумайте пароль и имя пользователя (латиницей, например `ivan-kuzmuk`).
   **Имя пользователя войдёт в адрес сайта**, выбирайте короткое и понятное.
3. Подтвердите почту кодом из письма.
4. На вопросы анкеты можно отвечать как угодно или пропускать (Skip). Тариф: **Free**.

---

## Шаг 2. Создайте репозиторий

Репозиторий — это папка проекта на GitHub.

1. Войдите на <https://github.com>, справа вверху нажмите **+** → **New repository**.
2. **Repository name**: `plants-health` (латиницей, без пробелов; это станет частью адреса сайта).
3. Выберите **Public** (бесплатный хостинг Pages работает для публичных репозиториев).
4. Галочки «Add a README», «.gitignore», «license» **не ставьте**.
5. Нажмите **Create repository**. Откроется пустая страница репозитория, не закрывайте её.

---

## Шаг 3. Загрузите файлы

Есть два способа. **Рекомендую способ А**: он загружает всё за один раз, включая скрытую
папку `.github`, без которой сайт не будет сам пересобираться.

### Способ А. Программа GitHub Desktop (рекомендуется)

1. Скачайте программу: <https://desktop.github.com>, установите (перетащите в «Программы»)
   и запустите.
2. Нажмите **Sign in to GitHub.com**, войдите в свой аккаунт в открывшемся браузере
   и разрешите доступ (**Authorize desktop**). Вернитесь в программу.
3. В меню выберите **File → Clone repository…**, вкладка **GitHub.com**, выберите
   `plants-health`. В поле **Local path** укажите, куда сохранить, например
   `Документы/GitHub/plants-health`. Нажмите **Clone**.
   Программа предупредит, что репозиторий пуст, это нормально.
4. Откройте в Finder папку `site` (из архива или из `PlantsHealth/site`).
   Нажмите **Cmd + Shift + .** (точка), чтобы увидеть скрытые файлы: должны появиться
   папка `.github` и файл `.nojekyll`.
5. Выделите **всё содержимое** папки `site` (Cmd + A) и скопируйте в папку
   `plants-health`, созданную на шаге 3. Важно: копируйте содержимое, а не саму папку
   `site`. Внутри `plants-health` должны лежать `index.html`, `recipes` и т. д.
6. Вернитесь в GitHub Desktop. Слева появится список файлов (их около 640).
   Внизу слева в поле **Summary** напишите `Первая загрузка сайта` и нажмите
   **Commit to main**.
7. Нажмите синюю кнопку **Publish branch** (или **Push origin**) вверху.
   Загрузка ~55 МБ займёт пару минут.

### Способ Б. Через браузер, без программ

1. На странице пустого репозитория нажмите ссылку **uploading an existing file**.
2. Браузер принимает не больше 100 файлов за раз, поэтому загружайте частями:
   - сначала файлы из корня `site` (`index.html`, `config.js`, `README.md`,
     `ИНСТРУКЦИЯ.md`, `шаблон-карточки.md`) и папки `assets`, `data`, `scripts`;
   - затем папку `recipes` в 5 приёмов по ~90 файлов.

   Папки перетаскивайте целиком, а не файлы из них, чтобы сохранилась структура.
   После каждой части внизу нажимайте **Commit changes**.
3. Скрытая папка `.github` через браузер обычно не перетаскивается. Создайте её файл вручную:
   **Add file → Create new file**, в имени файла наберите
   `.github/workflows/pages.yml` (косые черты сами создадут папки), откройте файл
   `site/.github/workflows/pages.yml` в «Текстовом редакторе» (если не видно, нажмите
   Cmd + Shift + . в Finder), скопируйте весь текст, вставьте и нажмите **Commit changes**.

---

## Шаг 4. Включите GitHub Pages

1. В репозитории откройте вкладку **Settings** (шестерёнка вверху).
2. В меню слева выберите **Pages**.
3. В разделе **Build and deployment** → **Source** выберите **GitHub Actions**.
   Больше ничего нажимать не нужно.
4. Откройте вкладку **Actions** вверху. Если там пусто, сделайте любое изменение
   (например, отредактируйте `README.md` через карандаш и нажмите **Commit changes**)
   или выберите слева «Сборка и публикация сайта» → **Run workflow**.
5. Подождите 1–2 минуты, пока у запуска появится зелёная галочка ✓.
6. Вернитесь в **Settings → Pages**: вверху будет надпись
   **Your site is live at https://ВАШЕ-ИМЯ.github.io/plants-health/**. Готово!

Если галочка красная ✗, нажмите на запуск и посмотрите, на каком шаге ошибка.
Самая частая причина: на шаге 4.3 не выбран источник **GitHub Actions**.

---

## Шаг 5. Как добавлять и менять рецепты

Всё делается с самого сайта, программы не нужны. Перед этим войдите на github.com
в том же браузере.

**Добавить рецепт**
1. На сайте нажмите **+ Добавить**, заполните форму. Справа видно, как будет
   выглядеть карточка. Черновик сохраняется в браузере.
2. Нажмите **Создать на GitHub**. Откроется GitHub с готовым файлом в папке `recipes`.
3. Нажмите зелёную **Commit changes…**, затем ещё раз **Commit changes** в окошке.
4. Через 1–2 минуты рецепт появится на сайте, в поиске и во всех указателях.

**Изменить рецепт**
1. Откройте рецепт на сайте, нажмите **✎ Изменить**, исправьте поля.
2. Нажмите **Сохранить на GitHub**: новый текст скопируется, откроется редактор файла.
3. В редакторе нажмите Cmd + A, затем Cmd + V и **Commit changes**.

Небольшую опечатку можно поправить сразу: кнопка **Править файл на GitHub** на
странице рецепта открывает файл в редакторе.

**Удалить рецепт**: откройте файл в папке `recipes` на GitHub, меню **…** справа вверху →
**Delete file** → **Commit changes**.

Если вы работаете через GitHub Desktop: кладите новые `.md` файлы в папку `recipes`,
затем **Commit to main** и **Push origin**. Сайт пересоберётся сам.

## Частые вопросы

**Сайт не обновился после изменения.** Откройте вкладку **Actions**: сборка идёт
1–2 минуты. Затем обновите страницу сайта с очисткой кэша: Cmd + Shift + R.

**Кнопка «Создать на GitHub» ведёт не туда.** Это бывает, если у сайта свой домен.
Откройте `config.js` и впишите имя пользователя и название репозитория.

**Можно ли сделать сайт закрытым?** Бесплатный GitHub Pages публикует сайт для всех,
у кого есть ссылка. Поисковики найдут его не сразу, но скрыть его паролем на
бесплатном тарифе нельзя.

**Собрать каталог у себя на компьютере** (не обязательно, GitHub делает это сам):
в «Терминале» перейдите в папку сайта и выполните `python3 scripts/build.py`.
